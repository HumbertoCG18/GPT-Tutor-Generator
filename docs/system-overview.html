Precedência absoluta: manual_unit_slug e manual_timeline_block_id sobrescrevem o automático com confiança = 1.0. manual_tags nunca são tocadas. O portão best ≥ 0.95 do scorer vive só no roteamento do FILE_MAP (navigation.py); quando recusa, o resolver cai no fallback "pega o melhor".

3 Sinais de Pontuação Bloco-Temporal

Como score_entry_against_timeline_block() soma evidências. Boosts positivos atraem o material para o bloco; penalidades empurram para fora quando a unidade do bloco contradiz a unidade preferida.

  • Unidade preferida casa o bloco+ unit_confidence × 0.25+0.35
  • Unidade preferida ≠ unidade do blocopenalidade off-unit−0.45
  • Tópico primário casa+ topic_confidence × 0.35+0.80
  • Tópico compatível (não primário)timeline_block_matches_preferred_topic+0.48
  • Tópico do bloco divergeblock_topic_slug presente−0.18
  • manual_tags casam tokens do tópicoweight 0.35+w
  • auto_tags / legacy_tagsweight 0.12 / 0.05+w
  • Evidência de cardsclamp em 0.45≤+0.45
  • Data exata dentro do períodoDATE_STRONG_BOOST · ex: "12.03 Processos.pdf"+0.30
  • Mês compatível, fora do rangeDATE_WEAK_BOOST+0.10

Boost de data (Fase 2) substituiu o regex DD.MM-no-início: agora extract_dates() lê datas de qualquer posição (título/markdown/raw) e o ano do próprio bloco resolve datas year-less do material. Regex ancorada distingue número de versão de data DD.MM.

4 Faixas de Confiança (Fase 3)

A confiança de bloco vem de margin_confidence(best, runner_up, k=0.18), clampada em [0,1]. Como o resolver sempre "pega o melhor", a band sinaliza ao revisor quão marginal foi a escolha.

baixa
< 0.20
mal supera o runner-up (~0.17 piso estrutural)
média
0.20 – 0.50
marginal, merece revisão
alta
≥ 0.50
gap claro, best ~1.0
0.0BAND_LOW = 0.20BAND_HIGH = 0.501.0

Persistida em computed_block_band no manifest e exposta na saúde/dashboard. Calibração reusa o piso de tag de bloco (BLOCO_TAG=0.50) sem rebalancear nada.

8.2 — Material A: a data manda

📄 12.03 Processos.pdf

Entrada nos signals: raw_text = "12 03 processos" · title = "Processos". Sem tags manuais. auto_map_entry_unit não confia (winner < 0.5 → unidade ambígua, sem boost/penalidade de unidade). Resta o texto fraco + a data. score_entry_against_timeline_block roda contra os 5 blocos:

BlocoSinal dominanteDataTextoScoreVisual
bloco-0112/03 ∈ [11/03, 13/03] → boost FORTE+0.30+0.050.35
bloco-02mesmo mês (março), fora do range → boost FRACO+0.10+0.020.12
bloco-03feriado, abril≠março, sem texto0.000.000.00
bloco-04abril, sem data casando0.00+0.010.01
bloco-05prova, abril0.000.000.00
winner = bloco-01 (0.35) · runner_up = bloco-02 (0.12)
margin_confidence(0.35, 0.12, k=0.18) = (0.35 − 0.12) + 0.35×0.18 = 0.23 + 0.063 = 0.293
confidence_band(0.293) → média (0.20 ≤ 0.293 < 0.50)

Resultado gravado em auto_tags: ["bloco:bloco-01", "unit:unidade-01-logica"] + computed_block_band: "media". A band média sinaliza ao revisor: "casou pela data, texto fraco — confira". O delta de data +0.30 é determinístico (assert no teste, linha 159).

Sem data no nome. Mas o texto casa topic_text = "indução estrutural sobre termos" do bloco-02. O boost de tópico-compatível (+0.48) domina, mesmo o bloco-02 tendo topic_ambiguous: true e primary_topic_slug vazio.

8.4 — Material C: órfão

📄 Artigo - Teoria das Categorias.pdf

Nenhuma data, nenhum tópico casa, texto fora do vocabulário do cronograma. Todos os blocos pontuam ~0. Como blocos existem, ainda assim "pega o melhor" — mas o melhor é fraco: computed_block_band: "baixa" baixa. Órfão de verdade (sem bloco:) só ocorreria se o cronograma não tivesse nenhum bloco instrucional.
